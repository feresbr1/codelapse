This is 100 commits of Express's response.js, the file behind res.send() and res.redirect(), in 30 seconds.

I built codelapse, an open-source tool that turns any file's git history into a time-lapse.

▶️ Lines keep their identity across commits, so the code slides into place as it evolves. Edits flash amber, new lines fade in green, deleted ones fade out red.

🔎 Click any line to see its life story: who wrote it, when, and every change since. Like git blame, but the whole story instead of the last change. Express's res.redirect() line has been edited 11 times since 2013.

🎬 Export the time-lapse as an MP4 or GIF, in 16:9, square or vertical, rendered entirely in your browser. That's how this video was made.

💻 Works on any GitHub file from the website, and on any local repository (private ones included) with one command:
npx github:feresbr1/codelapse src/app.ts

It's a great way to show how a project grew, explain a refactor, or just watch a file you've lived in for years.
